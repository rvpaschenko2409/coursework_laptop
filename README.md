# Выбор ноутбука для сотрудников

Курсовая работа. Вариант 27.

## Цель
Разработать систему поддержки принятия решений для выбора
ноутбука под требования сотрудников с прогнозом производительности
по техническим характеристикам.

## Методы
- DEMATEL — анализ взаимного влияния критериев.
- MEREC — определение весов критериев.
- MARCOS и VIKOR — сравнение и ранжирование ноутбуков.

## Технологии
Python, FastAPI, PostgreSQL.

## Текущее состояние
Создано виртуальное окружение Python 3.12.10.
Настроен Git.

## Сценарий использования
Выбор ноутбуков для офисных сотрудников, работающих
с документами, электронными таблицами, браузером и видеосвязью.

## Критерии выбора
- Цена — минимизация.
- Прогнозная производительность — максимизация.
- Масса — минимизация.
- Автономность — максимизация.
- Срок гарантии — максимизация.

## Дополнительные требования варианта
Сравнение способов нормирования.
Системный анализ: SSM (CATWOE и корневое определение),
модель Митчелла, DEMATEL.

## Основной сценарий работы
1. Пользователь создаёт проект выбора ноутбука.
2. Добавляет ноутбуки: характеристики, цену, массу,
   автономность и срок гарантии.
3. Система прогнозирует производительность с помощью
   обученной модели машинного обучения.
4. Система рассчитывает веса критериев методом MEREC.
5. Методы MARCOS и VIKOR формируют рейтинги ноутбуков.
6. Пользователь сравнивает результаты и влияние
   выбранного способа нормирования.
7. Пользователь выгружает отчёт с результатами.

Система помогает обосновать выбор.
Окончательное решение принимает пользователь.
