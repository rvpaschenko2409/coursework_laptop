# Выбор ноутбука для сотрудников

Курсовая работа. Вариант 27.

## Цель
Разработать систему поддержки принятия решений для выбора
ноутбука под требования сотрудников с прогнозом производительности
по техническим характеристикам.

## Методы
- DEMATEL — анализ взаимного влияния критериев.
- MEREC — определение весов критериев.
- MARCOS и VIKOR — сравнение и ранжирование ноутбуков.

## Технологии
Python, FastAPI, PostgreSQL.
