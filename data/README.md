# Паспорт учебных данных

## Обучающий набор

- Название: условные конфигурации ноутбуков с моделируемой производительностью.
- Файл: `data/synthetic/laptops_synthetic.csv`.
- Происхождение: собственная генерация, `data_origin=synthetic` для всех строк.
- Генератор: `python -m scripts.generate_synthetic`, seed=42, 2000 строк.
- SHA-256 оригинального CSV: `771654654dffb8134a47dea1e001a99e5e7ec8e6d55e60ac18b3b9d8d616a31e`.
- Назначение: контролируемая проверка восстановления заданной зависимости.
- Реальные пользователи, персональные данные и реальные тесты устройств отсутствуют.

| Поле | Единица или тип | Назначение |
|---|---|---|
| sample_id | целый номер | Идентификатор наблюдения, не ML-признак |
| cpu_cores | ядра | ML-признак |
| cpu_threads | потоки | ML-признак, связан с профилем CPU |
| cpu_frequency_ghz | ГГц | ML-признак |
| ram_gb | ГБ | ML-признак |
| storage_type | HDD или SSD | Категориальный ML-признак |
| storage_gb | ГБ | Дополнительный ML-признак, частично дублирует тип диска |
| synthetic_score | условные баллы | Целевая переменная |
| data_origin | synthetic | Происхождение, не ML-признак |

Число уникальных полных конфигураций — 100. Профили CPU:
(2,4,2.0), (4,4,2.5), (4,8,2.5), (6,12,2.8), (8,16,3.0).
ОЗУ: 4, 8, 16, 32 ГБ. SSD: 256, 512, 1024 ГБ. HDD: 500, 1000 ГБ.
В каждой тройке CPU указаны ядра, потоки, ГГц. Это учебные профили.

Профиль CPU, память и тип диска выбираются независимо и равновероятно.
Ёмкость выбирается равновероятно среди значений своего типа.
Формула: C=(cores/4)^0.7·(frequency/2.5), M=(RAM/8)^0.3,
D=1 для SSD и 0.4 для HDD, S=1000/(0.7/C+0.2/M+0.1/D).
К S применяется логнормальный множитель с параметрами log-среднего
−0.00125 и log-стандартного отклонения 0.05; итог округляется до 0.01.
Параметры заданы автором сценария, не оценены на реальных измерениях.

## Качество и разбиение

Пропуски, повторы sample_id, неположительные цели и нарушения допустимых
конфигураций не обнаружены. Намеренная доля дефектов — 0.
Повторные наблюдения одной конфигурации допустимы как повторы с шумом.
Среднее цели 1016.78, медиана 1005.74, стандартное отклонение 318.95.
Минимум 469.32, максимум 1918.19.

GroupShuffleSplit с seed=42 и test_size=0.2 разделяет конфигурации:
обучение — 1608 строк и 80 конфигураций, тест — 392 строки и 20 конфигураций.
`configuration_id` добавлен только в processed/train.csv и processed/test.csv.
GroupKFold(5) на обучающей части используется для настройки моделей.
Отдельное тестовое множество не используется для выбора параметров.

Проверки: `python -m scripts.audit_project` и `python -m pytest -q`.
Диагностики качества: `results/audit_project.json`.
SHA-256 зависит от представления файла и переводов строк. Временная
регенерация проверяется по точному равенству содержимого таблиц,
поэтому различия переводов строк между ОС не принимаются за новые данные.

## Остальные наборы

`data/raw/notebook_cpu_performance.zip` — архив открытого кандидата Pierre
Haessig, CC BY 4.0; ссылка и дата получения — в docs/data_sources.md.
Он не является источником synthetic_score и не использован в обучении.
`data/decision/alternatives.csv` — 5 вымышленных альтернатив A1–A5;
их цены и характеристики — допущения, происхождение synthetic.
`data/decision/dematel_direct.csv` — учебные оценки влияния 0–4;
они не получены опросом реальных экспертов.

## Ограничения и обновление

Реальная точность и рыночное правдоподобие не установлены.
Формула, данные и модели соответствуют одной версии эксперимента.
Изменение генератора требует нового разбиения, обучения и пересчёта
производных результатов. Нельзя выдавать прежний тест за независимую
проверку после настройки генератора или модели по этому тесту.
