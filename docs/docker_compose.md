# Локальный запуск в Docker Compose

Из корня проекта при запущенном Docker Desktop:

```powershell
docker compose up --build -d --wait
docker compose ps -a
```

Откройте http://127.0.0.1:8001/login. Для учебного проекта используйте
`docker-demo@example.com` и пароль `LaptopDemo2026!`. При первом запуске Compose
скачивает образы и устанавливает Python-зависимости. Сервис `setup` выполняет
миграции Alembic, загружает демонстрационные данные и регистрирует модели.
После успешной подготовки `setup` завершится с кодом 0, а `web` станет healthy.

Стенд рассчитан на локальную демонстрацию. Веб-порт доступен с этого компьютера,
порт PostgreSQL наружу не публикуется. Пароли в конфигурации предназначены для
демонстрации. Для собственного локального стенда задайте
`COURSEWORK_DB_PASSWORD`, `COURSEWORK_APP_PASSWORD` и
`COURSEWORK_DEMO_PASSWORD` в окружении перед первым запуском.
Изменение этих переменных не меняет пароли, уже записанные в базе.

```powershell
docker compose logs setup web
docker compose down
docker compose up -d --wait
```

Остановка через `down` сохраняет тома PostgreSQL и обученных моделей.
Удаление томов удалит данные стенда. Compose использует собственный PostgreSQL
16, локальная база Windows и порт 8000 работают отдельно.

Для проверки откройте учебный проект, запустите MARCOS и VIKOR,
остановите и снова запустите Compose. Сохранённый расчёт должен открыться.
