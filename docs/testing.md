# Проверки проекта

## Нормирование критериев

Дата запуска: 12.10.2026.
Команда: python -m pytest tests/test_normalization.py -q
Результат: 24 passed.

Проверены функции normalize_ratio и normalize_minmax:
- соответствие ручному контрольному примеру;
- обработка постоянного столбца;
- отсутствие изменений исходной таблицы;
- независимость результата от порядка входных столбцов;
- отклонение нулей, отрицательных значений, NaN и бесконечности;
- отклонение пустой матрицы и отсутствующего критерия;
- отклонение повторяющихся столбцов и идентификаторов.

Дополнительно результаты переноса обеих функций
сверены с ранее сохранёнными расчётами:
максимальное отклонение — около 5,55 × 10⁻¹⁷
при допуске 10⁻¹².

Эти проверки относятся к модулю нормирования.
Остальные расчётные методы и приложение требуют
отдельного тестирования.

## Метод MEREC

Дата запуска: 12.10.2026.
Команда: python -m pytest tests -q
Результат: 30 passed — 24 проверки нормирования
и 6 проверок MEREC.

Для MEREC проверены:
- равные эффекты и веса на симметричном ручном примере;
- нулевой вес постоянного критерия;
- отказ от расчёта весов для одинаковых альтернатив;
- неизменность весов при смене единиц измерения;
- сохранность исходной таблицы;
- независимость результата от порядка столбцов.

При сверке перенесённой функции с ранее сохранёнными
эффектами и весами максимальное отклонение составило
около 8,33 × 10⁻¹⁷ при допуске 10⁻¹².
