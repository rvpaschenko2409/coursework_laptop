## Метод DEMATEL

Дата запуска: 23.10.2026.
Команда: python -m pytest -q
Результат: 57 passed, включая 9 проверок DEMATEL.

Проверены:
- нормирование, полное влияние и показатели на ручном примере;
- косвенное влияние в цепочке из трёх критериев;
- сохранность исходной таблицы;
- полный эффект взаимного влияния при сходящемся цикле;
- отклонение цикла, не удовлетворяющего условию сходимости;
- отклонение нулевой матрицы;
- отклонение оценок вне диапазона 0–4, NaN и бесконечности;
- отклонение несовпадающего порядка критериев.

Сверка с сохранёнными результатами выполнена командой:
python -m scripts.check_dematel_transfer

Нормированная матрица, матрица полного влияния и показатели
совпали с прежним расчётом. Максимальное отклонение — 0,0
при допуске 10⁻¹².

Основной скрипт и анализ чувствительности подключены
к функции calculate_dematel из decision_core.dematel.
При переносе анализа чувствительности проверены обе таблицы:
сводка восьми сценариев и подробные показатели критериев.
Результаты совпали при допуске 10⁻¹².

Во всех восьми сценариях классификация критериев сохранилась.
Этот вывод относится к изменению каждой ненулевой оценки
на один балл в пределах шкалы 0–4.
