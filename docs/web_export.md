# Экспорт отчёта о решении в XLSX

Вариант 27. Реализован экспорт по ФТ-13 ТЗ: цель, ограничения, исходная матрица и источники значений, веса, результаты методов и условия VIKOR, версии данных и модели, метрики ML, дата и идентификатор расчёта. Дополнительно включены диаграмма сравнения рангов, промежуточные вычисления и связанное решение ЛПР.

Основание: `technical_specification.docx`, раздел 4, ФТ-13, и методическое пособие, раздел об экспорте отчёта (печатные страницы 92–93). XLSX является выбранным форматом обязательного отчёта; DOCX и PDF этим этапом не добавляются.

## Использование

После перезапуска сервера откройте результат MARCOS и VIKOR и нажмите «Скачать отчёт Excel». На странице сохранённого решения доступна отдельная кнопка «Скачать отчёт Excel с решением ЛПР».

Экспорт доступен всем участникам соответствующего проекта: аналитику, эксперту и ЛПР. Принадлежность проекту проверяется на сервере. Изменений БД, новых прав PostgreSQL и установки пакетов не требуется.

## Состав книги

| Лист | Содержание |
| --- | --- |
| Отчёт | Название, цель, бюджет, идентификаторы пары, дата и автор расчёта, версии, источник весов, v, лидеры, компромиссный набор, ограничения и отпечаток контекста |
| Рейтинги | Общая таблица рангов и значений MARCOS и VIKOR, условия преимущества и устойчивости, компромиссный набор, диаграмма |

| Веса | Критерии, направления min/max, единицы, итоговые веса, компоненты комбинации или эффекты MEREC, обоснование и источник DEMATEL при наличии |
| Промежуточные | Нормированные и взвешенные матрицы, оценки исключения, идеал, антиидеал и другие сохранённые вычисления применённых методов |
| ML и источники | Использованные модели, версии, SHA-256, признаки, параметры, тестовые метрики, объём и способ разбиения, паспорт данных и связанные прогнозы |
| Решение ЛПР | Выбранный ноутбук, автор и дата, обоснование, ранги, принадлежность компромиссному набору и ссылка на прежнее решение |

Числа сохраняются числовыми ячейками, даты — датами Excel в часовом поясе Омска UTC+6. Отсутствующая дата обучения помечается «Не зафиксирована»; дата регистрации не выдаётся за дату обучения. Если связанных моделей или решения нет, книга сообщает об этом, без вымышленных данных.

Результаты представлены как фиксированный снимок. Изменение исходных ячеек Excel не пересчитывает MEREC, MARCOS и VIKOR. Диаграмма связана с ячейками рангов и может отражать ручное изменение этих ячеек; это не означает пересчёт методов.

## Привязка к истории

Отчёт расчёта загружается через проверенный `load_pair`, с воспроизведением исходной пары. Если для этой пары сохранено несколько решений, включается последнее связанное с ней решение. Решение из другого расчёта не подставляется. Совпадение контекстов дополнительно проверяется.

Экспорт со страницы решения воспроизводит его встроенный исторический контекст. Текущие названия, оценки, бюджет или модели не заменяют сохранённые значения. Такой отчёт остаётся доступен даже при отсутствии живой записи VIKOR, поскольку оба рейтинга сохранены в снимке решения. Состояние «последнее решение проекта» и отличие версии исходных данных показываются отдельно.

При изменении данных исторический XLSX разрешён, но содержит предупреждение и обе версии проекта. Состояние соответствует чтению при выгрузке; изменения проекта после скачивания не обновляют файл.

## Реализация и безопасность

- `export_data.py` получает и проверяет исторический источник; `export_rows.py` формирует разделы отчёта.
- `export_xlsx.py` заполняет подготовленный шаблон OOXML средствами стандартной библиотеки Python (`zipfile`, `ElementTree`). Стили и нативная диаграмма находятся в `assets/report_template.xlsx`; примерные данные в шаблоне очищены.
- `export_routes.py` предоставляет защищённые маршруты скачивания. GET не меняет расчёты, решения или журнал аудита; рабочие сессии обслуживаются существующим механизмом приложения.
- Весь пользовательский текст записывается как `inlineStr`, включая строки, начинающиеся с `=`, `+`, `-`, `@` или пробела. Формулы ячеек из текста не создаются. В файле нет макросов, внешних ссылок и подключений.
- Книга содержит числовые кэши и ссылки внутренней диаграммы на ранги. Эти внутренние ссылки не формируются из пользовательского текста.
- Ограничения XML, длина ячейки 32767 символов, конечность чисел и предел 100000 строк на лист проверяются. Некорректный текст отклоняется сообщением; молчаливой подмены сохранённого текста нет.
- Ответ содержит `Content-Disposition: attachment`, тип XLSX, `Cache-Control: no-store` и `X-Content-Type-Options: nosniff`. Имя файла строится из числовых идентификаторов.

| Вид отчёта | Путь |
| --- | --- |
| Расчёт | `/projects/{project_id}/calculations/{result_id}/export.xlsx` |
| Решение ЛПР | `/projects/{project_id}/choices/{choice_id}/export.xlsx` |
| API | Те же пути с префиксом `/api` |

Идентификатор MARCOS или VIKOR одной пары даёт один источник и каноническое имя расчёта. Отсутствующий или чужой источник возвращает 404, отсутствие входа в API — 401, повреждённый снимок — 422.

## Проверка

```powershell
python -m pytest -q
python -m scripts.run_web
```

Общий автоматический прогон в изолированной PostgreSQL-совместимой среде: 300 пройденных тестов. Обычный режим без `TEST_DATABASE_URL`: 212 пройденных и 88 пропущенных проверок. Существующее предупреждение Starlette/AnyIO сохранено. Пропуски не подтверждают выполнение интеграционных проверок.

Проверены оба браузерных скачивания и страницы на пяти ширинах 360, 390, 768, 1366, 1920 пикселей. Книга повторно прочитана независимым средством, проверены значения, типы дат, форматы, внутренние ссылки диаграммы и её число точек. Контрольный файл также открыт и пересохранён LibreOffice Calc с сохранением значений в пределах точности Excel, дат и диаграммы. Изображения семи листов просмотрены; ограничение предварительного просмотра дат отдельно зафиксировано в протоколе.

После установки нужно скачать отчёт на пользовательском компьютере и открыть в Excel или LibreOffice: проверить лист «Решение ЛПР», диаграмму и совпадение с сайтом. Автоматическая проверка не выполнялась на пользовательской Windows/PostgreSQL и не является проверкой всех версий Microsoft Excel.

Состав изменённых файлов и результаты проверок: `web_export_checks.json`. Математическое ядро, адаптеры истории, данные, модели, миграции и стили сайта не изменяются. Интерактивные темы, фильтры, браузерный Python и PWA остаются следующими этапами.
