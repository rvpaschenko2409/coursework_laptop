### Результат первичной проверки

В 32 файлах исходных результатов Geekbench 6 содержится
27 655 записей тестирования. Ссылки на тесты уникальны.
Пустых значений в исходных столбцах не обнаружено.

Доступны название системы, модель процессора, частота,
количество ядер, дата загрузки, операционная система,
одноядерный и многоядерный баллы, ссылка на результат.

Объём оперативной памяти и характеристики накопителя
в записях тестирования отсутствуют.

Обнаружены 194 записи с явным указанием виртуальной
машины в названии системы. Требуется дополнительная
проверка состава устройств.

### Решение

В текущем контролируемом эксперименте этот источник не используется
для обучения. Сырые результаты не содержат ОЗУ и накопителя, необходимых
для выбранной модели конфигурации; CPU-тест не подменяет комплексный
балл всего ноутбука. Присоединение этих полей без подтверждённых
соответствий не выполнялось. Открытый архив сохранён для прослеживаемости
проверки кандидата. Его данные не смешиваются с синтетической выборкой.

## Используемый обучающий набор

Набор `data/synthetic/laptops_synthetic.csv` создан скриптом
`scripts/generate_synthetic.py` с зерном 42. Он содержит 2000 наблюдений
для 100 условных конфигураций. Цель — `synthetic_score`, условный балл
по явно заданной формуле; это не измеренный Geekbench или PCMark.
Модели Ridge и Random Forest обучены на этом наборе. Паспорт,
параметры и ограничения приведены в `data/README.md` и `docs/synthetic_data.md`.

Основание выбора — контролируемый эксперимент с заранее известной
зависимостью, допустимый по разделу 4.6.3 методички. Доли времени,
степени и коэффициент HDD — авторские допущения, а не параметры,
оценённые по открытым данным. Их переносимость на реальное оборудование
не доказана; эмпирическая калибровка остаётся отдельной задачей.
