# Источники данных

## Notebook CPU performance

Автор: Pierre Haessig.
Источник: https://github.com/pierre-haessig/notebook-cpu-performance
Лицензия, указанная автором: CC BY 4.0.
Дата получения: 10.10.2026.
Локальный архив: data/raw/notebook_cpu_performance.zip.

### Результат первичной проверки

В 32 файлах исходных результатов Geekbench 6 содержится
27 655 записей тестирования. Ссылки на тесты уникальны.
Пустых значений в исходных столбцах не обнаружено.

Доступны название системы, модель процессора, частота,
количество ядер, дата загрузки, операционная система,
одноядерный и многоядерный баллы, ссылка на результат.

Объём оперативной памяти и характеристики накопителя
в записях тестирования отсутствуют.

Обнаружены 194 записи с явным указанием виртуальной
машины в названии системы. Требуется дополнительная
проверка состава устройств.

### Решение

Источник рассматривается как кандидат.
Окончательная обучающая выборка пока не сформирована.
Для соответствия задаче необходимо дополнить данные
либо подобрать другой источник.
