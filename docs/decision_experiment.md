# Учебный эксперимент по выбору ноутбука

## Исходные данные
Сравниваются пять вымышленных альтернатив A1–A5.
Характеристики, цены, масса, автономность и гарантия
заданы как допущения учебного сценария.
Они не являются предложениями магазинов или результатами
испытаний реального оборудования.

Конфигурации соответствуют допустимым сочетаниям
характеристик синтетического генератора.
Производительность будет рассчитана сохранённой моделью
случайного леса в условных баллах.

## Критерии
Цена и масса — минимизация.
Прогнозная производительность, автономность
и срок гарантии — максимизация.

## Ограничения
Для демонстрационного сценария принят бюджет
не более 100000 рублей за ноутбук.
Все пять альтернатив удовлетворяют этому ограничению.

## Назначение
Проверить последовательность расчётов MEREC, MARCOS
и VIKOR, сравнить результаты и способы нормирования.
Эксперимент не является рекомендацией к реальной покупке.

## Результаты MARCOS

Добавлены идеальная AI и антиидеальная AAI альтернативы.
Нормирование выполнено относительно идеала:
для минимизируемых критериев — AI / значение;
для максимизируемых — значение / AI.

Использованы веса MEREC.
Взвешенные суммы ориентиров:
S_AI = 1;
S_AAI ≈ 0,395540.

Контрольная подстановка для A4 по округлённым значениям:
K_minus = 0,711635 / 0,395540 ≈ 1,799148;
K_plus = 0,711635 / 1 = 0,711635;
f_minus ≈ 0,283432;
f_plus ≈ 0,716568;
итоговая полезность ≈ 0,639897.

Контроль совпал с программным результатом до шести знаков.
В основном расчёте промежуточные значения не округлялись.

Коэффициенты f_minus и f_plus постоянны для данной матрицы:
при вычислении их отношений сумма конкретной альтернативы
сокращается.

По MARCOS лидирует A4. Метод допускает компенсацию
слабых значений одних критериев сильными значениями других.
A2 и A5 имеют близкие оценки; устойчивость их порядка
пока не проверена.

Результат относится к учебной матрице и выбранным весам.
Итоговая полезность не является вероятностью.
