# Обновление интерфейса: Night Circuit

Этап `feature/ui-redesign`, 01.11.2026, вариант 27.
Цель — современный интерфейс с игровыми акцентами при сохранении требований
ТЗ к читаемости, адаптивности, доступности и представлению расчётов.

## Что изменилось

Тёмный фон, сине-фиолетовые и мятные акценты, объёмные карточки,
обновлённые кнопки и видимые состояния наведения и клавиатурного фокуса.
На страницах входа и проектов есть декоративное изображение ноутбука,
выполненное средствами CSS и SVG. Оно не представляет конкретную модель
и не содержит вымышленных измерений.

На странице проекта добавлены карточки имеющихся ноутбуков. Ядра, потоки,
память, накопитель, цена и балл берутся из тех же данных, что и таблица.
Прогнозы и ручные корректировки сохраняют свои пометки. Полная таблица,
предупреждения о синтетике и все прежние действия остаются доступны.
Карточки не присваивают ноутбукам рейтинг до выполнения расчёта.

Шаблоны остальных модулей получают ту же тему: формы, таблицы, история,
DEMATEL, веса, чувствительность и заинтересованные стороны. Изображения
диаграмм оставлены на светлом фоне, чтобы сохранить читаемость осей, цветов
и научных графиков. Числовые таблицы доступны рядом.

Меню учётной записи раскрывается нажатием на имя в правой части шапки.
В нём находятся API и кнопка выхода. Использован стандартный HTML details:
Enter открывает и закрывает меню, Tab переводит фокус между действиями.
Для работы темы и меню JavaScript не требуется.

На странице DEMATEL уточнена прежняя устаревшая подпись: нормированные D+R
уже можно явно выбрать на странице весов. Расчёт этим изменением не затронут.

## Сохранность функций

Изменены только CSS и шаблоны HTML. Ни один Python-модуль, маршрут API,
математическая формула, модель, набор данных, право доступа и миграция
не заменяется. Сохранённые результаты остаются прежними.
Все формы сохраняют адреса, имена полей и CSRF. Новые карточки используют
имеющиеся данные без нового запроса к БД.

Зависимости и внешние шрифты не добавляются. Используются системные шрифты,
локальный Bootstrap, CSS и SVG. Прежняя CSP с script-src 'none' сохранена.
Новый параметр версии в URL CSS предотвращает показ старой закэшированной темы.

## Требования ТЗ и проверки

- Проверены ширины 360, 390, 768, 1366 и 1920 px.
- Общей горизонтальной прокрутки нет; широкие таблицы имеют свой контейнер.
- Проверенный текст интерфейса имеет размер не меньше 16 px.
- Проверенные видимые ссылки, кнопки, поля и раскрывающиеся заголовки
  имеют область не меньше 44×44 px. Для checkbox проверяется связанная метка.
- Основные цветовые пары текста имеют контраст не меньше 4,5:1.
  Отдельно проверены обводки полей и фокус по порогу 3:1.
- Клавиатурой проверены ссылка перехода к содержимому и раскрытие профиля.
- При prefers-reduced-motion: reduce отключаются анимации и переходы.
- Постоянного мигания, пульсации и автодвижения нет.

Проверено 31 состояние на пяти ширинах: 155 внутренних снимков.
На каждом проверены отсутствие общей прокрутки, размеры текста и целей.
В том числе открыты вход, регистрация, проекты, карточки, редакторы,
DEMATEL, CATWOE, веса, результаты, чувствительность, реестр сторон и ошибки.
Контроль MEREC сохранён: MARCOS A4 с полезностью 0,639897;
VIKOR — A2, компромиссный набор A2, A3, A5.

## Установка

Остановить сервер Ctrl+C. Распаковать архив на рабочий стол.
Из чистой ветки `feature/ui-redesign` выполнить:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\Desktop\coursework_ui_redesign\install_ui_redesign.ps1"
python -m scripts.run_web
```

Ввести пароль coursework_app, открыть http://127.0.0.1:8000 .
Если браузер оставил прежний вид, обновить Ctrl+F5. Новые права и миграции
не нужны. Установщик проверяет базовые версии семи файлов и сохраняет
их резервные копии перед заменой.

После просмотра выполнить во втором терминале `python -m pytest -q`
и `git status --short`. Ожидается 188 passed, 70 skipped, 1 warning.
Изменение оформляется отдельным коммитом ветки дизайна.

Этот архив обновляет оформление существующих функций. Он не добавляет PWA,
экспорт, обучение ML через веб или другие ещё не завершённые этапы курсовой.
