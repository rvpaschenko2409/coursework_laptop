# Требования к данным

## Обучающая выборка
По методичке необходимо не менее 500 наблюдений
и не менее пяти информативных признаков.

Целевой показатель — измеренный балл одного бенчмарка
определённой версии.

Предварительные признаки:
- модель процессора;
- количество ядер;
- количество потоков;
- объём оперативной памяти;
- тип накопителя;
- объём накопителя.

Окончательный состав признаков определяется после
проверки источника и полноты данных.

## Проверка источника
Необходимо установить:
- происхождение данных и условия использования;
- количество пригодных записей;
- наличие измеренного целевого показателя;
- пропуски и дубликаты;
- сопоставимость результатов тестирования.

## Таблица выбора ноутбуков
Для каждой конкретной комплектации нужны:
название, характеристики, цена, масса,
автономность, срок гарантии, источники и дата сбора.

Прогнозная производительность добавляется после
применения обученной модели.
