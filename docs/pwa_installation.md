# Подготовка PWA из чистой копии проекта

В Docker Compose Pyodide 0.27.7 устанавливается при сборке образа:

```powershell
docker compose up --build -d --wait
```

При запуске FastAPI напрямую установите Pyodide из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m scripts.install_pyodide
```

При первой установке нужен доступ к `cdn.jsdelivr.net`. Скрипт сверяет SHA-256
десяти файлов с `scripts/pyodide_assets.json`. Повторная установка использует
уже проверенные файлы. Если файлы есть на носителе, можно указать
`--source <папка>`. Дистрибутив Pyodide и колёса Python хранятся в
`web_app/static/pyodide`; перечень и контрольные суммы хранятся в Git.

## Проверка на Windows

1. Откройте проект на http://127.0.0.1:8001 и нажмите «Сохранить проект офлайн».
2. Дождитесь сообщения о сохранении, затем откройте ссылку на офлайн-копию.
3. Остановите веб-сервис командой `docker compose stop web`.
4. Обновите офлайн-страницу и измените параметр `v`. Таблица должна
   пересчитаться на сохранённой матрице через Python в браузере.
5. Возобновите работу командой `docker compose start web`.

Для установки на Android используйте пункт установки приложения в меню
браузера. На iPhone откройте офлайн-страницу в Safari по HTTPS и выберите
«Поделиться» → «На экран Домой». Адрес localhost в инструкции для Windows
относится к тому устройству, на котором запущен сервер.
