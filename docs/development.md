# Проверки проекта

Основные зависимости фиксируются в `requirements.txt`,
`requirements_database.txt` и `requirements_web.txt`. Инструменты разработки
устанавливаются отдельно.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements_dev.txt
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m pytest -q
```

Ruff проверяет синтаксис и ошибки обращения к именам во всех Python-модулях.
Дополнительный аудит `ruff check --select E9,F --statistics .` на коммите
`4f274be` выявил 105 замечаний Pyflakes: 69 неиспользуемых импортов,
31 повторное определение и 5 неиспользуемых переменных. Эти правила пока
не входят в обязательную проверку. Автоматическое переформатирование
существующего кода не выполнялось.

Для запуска через Docker Compose параметры можно задать в локальном файле
`.env` по образцу `.env.example`. Пустые значения включают локальные учебные
значения из Compose. Для нового экземпляра задайте свои значения до
создания базы. Изменение файла `.env` не меняет пароли уже созданных ролей.
Файл `.env` исключён из Git.

Для интеграционных тестов задайте `TEST_DATABASE_URL` в окружении PowerShell.
Используйте отдельную тестовую PostgreSQL. Без этой переменной тесты,
которым требуется тестовая база, пропускаются.
